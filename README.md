# Neru Memory

未来のための外部記憶。Task / Want / Future / Goal をまとめ、Google Calendar と Android Widget へ拡張する Flutter アプリです。

## Current build
- White × Blue responsive UI
- Home / Lists / Goals / Calendar placeholder / Settings
- Quick Capture
- Cross-type search
- Light / Dark / System theme switching (default Light)
- In-memory repository prototype and seed data
- Basic unit tests

## Next integration step
Firebase Authentication + Firestore + Google Calendar API + Android home widgets. These require project-specific Google/Firebase credentials and Android configuration.
