Neru Memory v1.5 Calendar Session Stability
上書きOK / 削除なし
ベース: v1.4.0.1 動作確認済み

今回の中心:
- アプリ起動後、以前使ったGoogleアカウントを軽量認証で自動復元
- Calendar画面を開いた時に毎回「接続」からやり直す挙動を改善
- Calendar API権限もUIなしで復元できるか確認
- RESTが401になった場合、古いアクセストークンのキャッシュを破棄して1回だけ自動再取得・再試行
- 自動更新中にGoogle同意画面を勝手に出さない
- 本当にユーザー操作が必要な場合だけ「接続」へ戻す
- 月移動・更新時も接続状態を自動復元

適用:
v1.4.0.1 の上から上書き
flutter run

確認:
1 Google Calendarを一度接続して予定が見える
2 アプリを完全終了
3 Neru Memoryを再起動
4 Calendarを開く
5 「接続」を押さずにGoogle予定が自動表示される
6 翌月→当月など月移動しても予定取得できる
7 アプリを数回終了/再起動しても接続が維持される

注意:
Google側が再同意を要求した場合だけ手動接続が必要です。
